## Claude에게: 진행 순서

사용자는 개발 경험이 없을 수 있다. 명령을 실행하기 전에 무엇을 왜 하는지 한 줄로 말하고, 오래 걸리는 단계(다운로드 10GB 이상, 생성 약 4분)는 미리 알린다.

1. **환경 확인**: OS, `nvidia-smi`(GPU 이름·VRAM·드라이버), 여유 디스크(20GB 이상), Python·ffmpeg 유무. NVIDIA GPU가 없으면 여기서 멈추고 이유를 설명한다.
2. **ComfyUI 설치**: 공식 안내(https://github.com/Comfy-Org/ComfyUI)를 따른다. Windows면 WSL2 Ubuntu 안 `~/ComfyUI` 또는 공식 Windows 포터블 중 사용자와 정한다. RTX 50 시리즈는 CUDA 12.8 이상 PyTorch(`cu128`)가 필요하다. 커스텀 노드는 필요 없다.
3. **모델 3개 받기**: README "환경" 표의 파일을 Hugging Face `Comfy-Org/Wan-2.1`의 `split_files/`에서 받아 표의 폴더에 넣는다.
4. **ComfyUI 켜기**: `127.0.0.1:8188` 접속 확인 (외부 공개 `--listen 0.0.0.0`은 하지 않는다).
5. **스크립트 준비**: `pip install pillow`, `ffmpeg`·`ffprobe` 확인.
6. **영상 자르기**: 사용자 영상에서 하늘이 넓고 앞쪽이 단순한 5초 구간을 같이 고른다(몇 장면 캡처해서 보여주기). README 따라 하기 2단계 `prepare`를 먼저 `--frames 49`로.
7. **밤 첫 장면**: `inputs49/first.png`를 사용자에게 주고, 이미지 AI에 `prompts/01_glow_night_image_edit.txt`를 참고해 "구도는 그대로 두고 밤 조명으로만 바꿔 달라"고 요청하게 한다. 받은 그림을 `night_first_frame.png`로 저장하고, 원본과 겹쳐 건물·길 위치가 같은지 확인한다.
8. **프롬프트**: `prompts/J_glow_sky_night.txt`를 바탕으로 사용자 영상에 보이는 것(하늘, 산, 길, 건물)에 맞게 고친다. 네거티브는 `prompts/v2v_negative.txt` 그대로.
9. **49프레임 시험** → 결과 비교 영상을 사용자와 확인. 네온 윤곽이 많으면 `--strength 0.6`, 건물이 바뀌면 0.8로 되돌린다. **한 번에 옵션 하나만** 바꾼다.
10. **81프레임 본편**: 2단계를 `--frames 81`로 다시 만들고 같은 설정으로 생성. 본편은 따로 확인한다.
11. 결과 영상 경로와 실행 시간을 사용자에게 알려준다. 결과는 AI가 만든 상상이므로 실제 야간 촬영처럼 소개하지 않도록 안내한다.
